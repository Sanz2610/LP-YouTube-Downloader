# Helper runtime for developers

Release phụ này giữ runtime Windows x64 để tái tạo gói offline. Người dùng thông thường tải ZIP offline ở release `v0.1.0`.

Các binary chưa chỉnh sửa: Node.js 24.15.0, yt-dlp 2026.08.19 và FFmpeg shared LGPL từ BtbN. Archive chứa license/notice, các checksum file nằm trong `helper/runtime.lock.json`. Source/upstream nằm trong `helper/SOURCES.json` và `THIRD_PARTY.md`.

`npm run setup:helper` tải archive, kiểm tra checksum rồi compile bridge từ `NativeBridge.cs`. Không đăng ký Native Messaging hay cài extension vào browser.
