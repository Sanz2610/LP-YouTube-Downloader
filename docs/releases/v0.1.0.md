# LP YouTube Downloader 0.1.0

Tải video YouTube trên Windows x64 với Edge hoặc Chrome.

**Người dùng tải `LP-YouTube-Downloader-0.1.0-offline.zip` trong Assets.** Gói này đã chứa extension, Node.js portable, yt-dlp và FFmpeg; không cần cài npm, Node hay FFmpeg riêng.

1. Giải nén ZIP vào một folder riêng.
2. Bấm `Install-LP-YouTube-Downloader.cmd`.
3. Mở `edge://extensions` hoặc `chrome://extensions`, bật Developer mode, chọn **Load unpacked**.
4. Chọn `%LOCALAPPDATA%\LP YouTube Downloader\extension`.
5. Mở video YouTube, bấm icon download ở góc phải video và chọn chất lượng.

Tải lại một bản mới: chạy installer, Reload extension và refresh YouTube. Không cần gỡ bản đang có.

Gói `extension.zip` chỉ chứa extension, dành cho người đã cài helper. GitHub **Source code (zip)** dành cho phát triển, không chứa runtime helper.

Có lựa chọn chất lượng, progress, Cancel và Mở thư mục sau khi tải xong. Popup toolbar hiển thị Developed by Lapphan, version và một nút GitHub. Icon toolbar/manifest được render từ cùng asset Lucide download trên nền đỏ.

Kiểm tra SHA-256 bằng `SHA256SUMS.txt`. Chỉ tải nội dung mà bạn có quyền tải. Không hỗ trợ livestream/DRM. Browser vẫn yêu cầu Load unpacked một lần; installer không tự sửa profile browser.
