# LP YouTube Downloader 0.1.1

- **Mở thư mục:** helper mở Explorer hiển thị trên desktop; sửa lỗi gọi Explorer với trạng thái cửa sổ ẩn. Đường dẫn có khoảng trắng hoặc dấu nháy được xử lý đúng.
- **Tải lại:** thêm nút Tải lại sau hoàn tất. Đóng rồi mở nút download hoặc reload YouTube đều trả về danh sách chất lượng, kể cả lịch sử cho biết video đã tải.
- **Giữ file cũ:** nếu cùng video/chất lượng đã có trong Downloads, lượt mới tạo file có hậu tố `(2)`, `(3)`…; không ghi đè file trước. Sau khi xóa file gốc vẫn tải lại được.
- **Tên thư mục:** trạng thái hoàn tất hiển thị tên Downloads theo thư mục helper đã cấu hình.

**Cập nhật từ 0.1.0:** tải `LP-YouTube-Downloader-0.1.1-offline.zip` trong Assets, giải nén và chạy `Install-LP-YouTube-Downloader.cmd`. Đây là thay đổi cả extension và helper; chỉ dùng `extension.zip` sẽ chưa cập nhật phần mở Explorer. Sau đó Reload LP YouTube Downloader trong `edge://extensions`/`chrome://extensions` và refresh YouTube.

Gói offline đã chứa Node.js portable, yt-dlp, FFmpeg và bridge. Không cần gỡ bản cũ hoặc cài dependency riêng. Xem README để cài lần đầu và `SHA256SUMS.txt` để kiểm tra file tải.
